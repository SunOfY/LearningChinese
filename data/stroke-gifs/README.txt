Optional stroke-order GIF folder

If you have your own stroke-order GIFs, upload them here.
File naming rule:
- 一個字對應一個 GIF
- filename = exact character + .gif
Examples:
  啊.gif
  爸. gif  (without space -> 爸.gif)
  媽.gif

When a GIF exists, the writing guide panel will show that GIF first.
If a GIF does not exist, the app falls back to HanziWriter online animation.
