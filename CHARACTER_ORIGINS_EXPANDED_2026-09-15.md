Each lesson keeps the same focused flow:
1. visual / ancient form / modern character
2. explanation + memory aid
3. vocabulary one item at a time
4. example sentences one item at a time
5. listening, AI pronunciation check, and writing practice

The data remains in `data/character-origins.json`, so future expansion can mostly be done by replacing that data file.
