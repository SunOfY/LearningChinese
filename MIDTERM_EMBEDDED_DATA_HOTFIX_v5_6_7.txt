v5.6.7 — Midterm embedded-data hotfix

Cause of HTTP 404:
The v5.6.6 Midterm tab fetched ./data/midterm_l1.json. If that exact nested file was not uploaded to GitHub Pages, the tab showed HTTP 404.

Fix:
- midterm_l1.json is embedded directly inside midterm.js.
- 42 Midterm illustration assets are also embedded as data URLs.
- No data/midterm_l1.json or data/midterm/images folder is required for the Midterm tab anymore.
- Service Worker cache version bumped to v5.6.7 and no longer pre-caches the missing JSON file.

Upgrade from v5.6.6: upload only midterm.js and sw.js.
